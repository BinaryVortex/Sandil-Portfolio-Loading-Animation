# Sandil Portfolio Loader

Sandil Portfolio Loader — a small and stylish loading animation built with HTML, CSS and a touch of JavaScript. It's lightweight, easy to drop into any portfolio or landing page, and simple to customize.

![Preview](./Screenshot%202024-08-28%20094640.png)

## Demo

Open `index.html` in your browser to see the loader in action.

## Features

- Smooth, visually pleasing CSS animation
- Minimal, easy-to-read HTML and CSS
- Simple to customize colors, size and timing
- No build tools required — just open the file

## Files

- `index.html` — markup and basic integration
- `style.css` — styles and animation
- `Screenshot 2024-08-28 094640.png` — preview image

## Usage

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Sandil-Portfolio-Loading-Animation.git

2. Open `index.html` in your browser.

3. To include the loader in an existing project, copy the relevant HTML from `index.html` and the animation rules from `style.css` into your project files.

### Quick example

Copy the loader markup into your page where you want the loader to appear:

```html
<!-- loader markup (from index.html) -->
<div class="loader">
  <div class="loader-inner"></div>
</div>
```

Then copy the animation rules from `style.css` (or link the stylesheet) and adjust the colors/sizes to match your design.

## Customize

- Change colors in `style.css` (search for color variables or root color values).
- Adjust animation-duration values to speed up / slow down the effect.
- Resize by changing width / height values on the loader elements.
